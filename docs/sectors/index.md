# 扇区文件

## 概述

扇区文件（.sct）定义了管制区域的边界和结构，是 EuroScope 等管制客户端运行的基础。

## 扇区列表

| 区域 | 说明 |
|------|------|
| [中国 FIR](/sectors/china) | 中国各飞行情报区扇区 |
| [东亚 FIR](/sectors/east-asia) | 日本、韩国、朝鲜、蒙古等 |
| [东南亚 FIR](/sectors/southeast-asia) | 东南亚各国飞行情报区 |

## 扇区类型

| 类型 | 地图样式 | 说明 |
|------|---------|------|
| CTR | 蓝色填充多边形 | 区域管制中心 |
| APP | 蓝色填充多边形 | 进近管制 |
| TWR | 白色点标记 | 塔台管制 |
| GND | 白色点标记 | 地面管制 |
| DEL | 白色点标记 | 放行管制 |

## 安装

参考[安装指南](/sectors/install)将扇区文件导入 EuroScope。
