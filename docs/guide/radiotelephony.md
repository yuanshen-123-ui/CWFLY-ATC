# 陆空通话

## 基本用语

| 中文 | 英文 | 含义 |
|------|------|------|
| 请求开车 | Request startup | 请求启动发动机 |
| 请求推出 | Request pushback | 请求推出停机位 |
| 请求滑行 | Request taxi | 请求滑行 |
| 请求起飞 | Request takeoff | 请求起飞 |
| 请求进近 | Request approach | 请求进近 |
| 复飞 | Go around | 取消进近复飞 |

## 通话示例

### 放行

```
机组：北京放行，中午好，CES1234，停机位A201，请求放行至上海
管制：CES1234，北京放行中午好，可以放行至上海，按计划航路，
      起始高度修正海压900米，应答机2345，通波A有效
机组：起始高度修正海压900米，应答机2345，通波A，CES1234
```

### 地面滑行

```
机组：北京地面，CES1234，请求滑行
管制：CES1234，北京地面，滑行至36L等待点，沿A-B-C滑行道
机组：沿A-B-C滑行道至36L等待点，CES1234
```

### 起飞

```
机组：北京塔台，CES1234，36L等待点，请求起飞
管制：CES1234，北京塔台，风向340风速4米秒，跑道36L，可以起飞
机组：可以起飞，CES1234
```
