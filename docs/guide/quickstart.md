# 快速上手

## 1. 安装管制客户端

### EuroScope

EuroScope 是连飞网络中最常用的管制客户端，支持雷达显示、飞行数据管理和通信功能。

- 下载地址：[EuroScope 官网](https://www.euroscope.hu)
- 安装完成后启动，配置 FSD 连接参数

### 连接参数

| 参数 | 值 |
|------|-----|
| 服务器地址 | 你的 FSD 服务器地址 |
| 端口 | 6809 |
| 登录名 | 你的 CID |
| 密码 | 你的平台密码 |

## 2. 加载扇区文件

1. 下载对应区域的扇区文件
2. 在 EuroScope 中打开扇区文件（.sct）
3. 确认扇区边界和频率正确加载

## 3. 开始管制

1. 确认 ATIS 信息已更新
2. 在对应频率上监听
3. 使用标准用语与机组通信
4. 记录飞行数据

## 4. 离岗

1. 移交未完成的管制任务
2. 通知接手管制员
3. 关闭客户端
