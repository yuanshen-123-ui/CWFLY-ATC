# 特情处理

## 通信失效

### 机组通信失效

1. 尝试备用频率联系
2. 通过其他飞机转达
3. 使用文本消息功能
4. 观察飞机是否按预期操作

### 管制席通信失效

1. 立即通知管理员
2. 启用备用通信设备
3. 使用文本消息指挥
4. 必要时移交至其他席位

## 紧急情况

### 发动机失效

- 优先保障该飞机使用跑道
- 清空空域和跑道
- 通知救援准备

### 特情航班

- 询问机组意图和需求
- 优先保障其飞行
- 通知相关席位协调
- 记录事件经过

## 违规处理

1. 记录违规情况（截图、日志）
2. 警告违规机组
3. 严重违规上报管理员
4. 填写事件报告
