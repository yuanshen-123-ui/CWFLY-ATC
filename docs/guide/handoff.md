# 协调移交

## 移交类型

| 类型 | 说明 |
|------|------|
| GND → TWR | 飞机到达跑道等待点 |
| TWR → APP | 飞机起飞后离开塔台频率 |
| APP → CTR | 飞机离开进近空域进入航路 |
| CTR → CTR | 飞机跨越区域边界 |
| CTR → APP | 飞机开始下降进入进近空域 |
| APP → TWR | 飞机建立五边或目视跑道 |

## 移交程序

1. 协调：提前与接收方协调移交条件
2. 移交：将飞机移交给接收方
3. 确认：接收方确认已建立通信
4. 完成：发送方确认移交完成

## 移交信息

移交时应包含以下信息：

- 航班呼号
- 当前高度
- 航向/航路
- 速度
- 特殊说明（如有）
